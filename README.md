One line of at most 200 characters: the phone battery's final message to the
charger it waited for all day.

`main.ts` writes the line to `/output/entry.txt`. It is deterministic and
fully offline — no network calls, no API keys, no model calls at runtime.

Run it with Node 22.18 or later:

```sh
node main.ts
```
